## 🌿 About Kauriflats

**Kauriflats** is a New Zealand rental and flatmate marketplace built to make finding a **home, room, flatmate, tenant, or rental property** easier, faster, and more trusted.

Visit the platform here: **[kauriflats.co.nz](https://kauriflats.co.nz)**

Kauriflats helps renters, students, professionals, landlords, property managers, and accommodation providers connect in one simple online marketplace. Whether someone is searching for a **room for rent**, a **shared flat**, a **full rental property**, or the **right flatmate**, Kauriflats is designed for the New Zealand housing market.
